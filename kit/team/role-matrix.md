# 角色矩陣與能力表（樣板）

**用途：** 多人協作的第一份必備文件（[docs/16 §2.2、§6.3](../../docs/16-team-collaboration.md)）。每月團隊會更新一次。
**注意：** 表中人員為虛構範例；公開 repo 不可填入真實姓名或內部資訊。

檢查：
- [ ] 每個任務恰有一位主責；備援不是主責本人
- [ ] 備援為環狀安排（兩人團隊除外，並已標示風險）
- [ ] 優先序為一條線，沒有並列
- [ ] 每人主責至多 2 個、備援至多 2 個（團隊可調整此上限）
